## The problem

An agent acts under a behavior policy `b` that picks Left or Right with equal probability. I
need the value of the start state under a target policy `π` that always picks Left. Since the
data was not generated by `π`, every return is reweighted by the importance sampling ratio
before being averaged.

```
            Left                 Left
   [A] ──────────────> [B] ──────────────> [Terminal]
    │   reward 0        │   reward 2
    │                   │
    │ Right             │ Right
    │ reward 1          │ reward 0
    v                   v
 [Terminal]         [Terminal]
```

The target policy follows A → Left → B → Left and collects 0 + 2, so the true value is
**V(A) = 2**. Averaging the raw returns without correction would instead converge to 1.0.

## Results

20 experiments of 10,000 episodes each, seed 0:

| Estimator | Mean | Standard deviation |
|---|---|---|
| Ordinary IS | 2.007160 | 0.034730 |
| Weighted IS | 2.000000 | 0.000000 |

The ordinary estimator's spread matches the analytical prediction √(12/10000) = 0.034641 to
within 0.3%. The weighted estimator is exactly 2 on every run, because every episode consistent
with the target policy has ρ = 4 and G = 2, leaving no randomness in the ratio of sums. Full
console output is saved in `results.txt`, and the reasoning is written up in `ANSWERS.md`.

## Tests

```bash

```

28 tests covering the transition table, the coverage assumption, trajectory frequencies,
returns and ratios against hand-worked values, both estimators including the edge case where no
episode survives the ratio, and the statistical properties the written answers rely on
(unbiasedness of ordinary IS, its spread matching sqrt(12/N), and weighted IS having the smaller
spread). The extensions are tested too: the chain at length 2 is asserted to reproduce the
assignment MDP's variance of 12, and the softened target policy is checked against the two values
where the answer is already known.
